# DPFS_luciana_rigo
BioKit Digital es una plataforma e-commerce desarrollada con Node.js y React para DH Venture Capitals. Comercializa kits de laboratorio, modelos 3D y recursos didácticos de biología. Ofrece una experiencia UI/UX fluida con catálogo dinámico, filtros pedagógicos, carrito de compras y panel de usuario para instituciones y docentes.
